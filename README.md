# object-detector-mini-
📌 Project Overview
This mini project demonstrates a basic object detection approach using classical computer vision techniques. The system detects and counts objects in a given image by converting it to grayscale, applying thresholding, and using connected component labeling.
The project is implemented in Python using popular image-processing libraries and is suitable for understanding the fundamentals of computer vision.

🎯 Objectives
Convert an image to grayscale
Segment objects from the background using thresholding
Detect and count objects in the image
Visualize detected objects using labels.

🛠️ Technologies Used
Python
Pillow (PIL) – Image handling
NumPy – Array operations
SciPy (ndimage) – Connected component labeling
Matplotlib – Visualization
